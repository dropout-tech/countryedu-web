# 鄉育官網｜色彩規格 v3「鮮豔版」（首頁全彩帶提案）

> 版本：2026.06.11　·　狀態：提案（基於 v2 反推色票上調飽和度；正式色號待甲方簽認）
> 對象：鄉育教育基金會 × DropOut(琢奧)
> 關係：v2（Sales Kit 反推版）仍是色彩「血統」依據；v3 不換色相、只調亮度與飽和度，並把彩色從點綴升級為**滿版色帶**。

---

## 0. 設計主張：從「白紙上的彩線」到「一條彩色的路」

v2 之後的首頁仍以白／米白為主、彩色只是線條與按鈕——客戶回饋「偏白、不夠耳目一新」。
v3 的解法不是再加新顏色，而是**讓既有的綠×橘×金直接成為區塊底色**：
使用者往下捲，等於走過一條由暖到綠、再回到暖、最後抵達橘色行動的路。
橘色滿版 CTA（已獲喜愛）就是這個語言的終點站——v3 把同樣的力度鋪滿整條路。

不變的紀律：亮、不灰、不霧；「撥開迷霧」只活在文案，不活在色彩。

標題色框（Mark）規則：只用亮綠 `#4F9F1D` 與路徑橘 `#F28C0A` 兩色、全頁交替；
白字、圓角、-1° 微傾斜；**僅限 h1/h2 大標關鍵字**（白字 on 綠 3.3:1、on 橘 2.5:1，正文禁用）；
每個標題最多一個色框，框內字數 2–4 字為佳。

## 3. 對比與可讀性規則（鮮豔版的安全帶）

| 組合 | 對比 | 判定／規則 |
|---|---|---|
| 白字 on 亮綠 `#4F9F1D` | 3.3:1 | 限大標（≥24px 粗體）；正文一律白卡承載 |
| 白字 on 路徑橘 `#F28C0A` | 2.5:1 | **只准標語級大字**（CTA 模式）；段落文字禁止 |
| 深林綠字 on 橘 `#F28C0A` | 3.4:1 | 橘帶上的次要文字用深林綠 |
| 墨綠字 on 蜜糖米／黃淡底 | >10:1 | ✓ 正文安全 |
| 白字 on 深林綠 `#3D5527` | 8.6:1 | ✓ 正文安全 |
| 金 `#FFBB1F` | — | 永不當文字色；只當底線、徽章、圖形 |

通則：**鮮豔底上不放正文**——正文永遠在白卡或淺 tint 上；滿版色帶只承載大標、一句副標與按鈕。這是「鮮豔但專業」與「鮮豔到刺眼」的分界線。
