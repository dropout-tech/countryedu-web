## 0. 設計主張

以一條 **由深到亮、全程錨定鄉育綠的「綠色光譜」**，把「撥開職涯的迷霧，看見你的專屬藍圖」說成同一個色彩故事：

- **迷霧端（深色）** 負責沉浸與戲劇張力 → 首屏 Hero、頁尾
- **藍圖端（淺色）** 負責內容閱讀與清晰 → 各內文區塊
- **鄉育綠** 是貫穿全站的品牌脊椎（沿用現有 CIS 主色）
- **晨光金** 是橫跨明暗的「指引光」，迷霧中的光點

設計動機：解決目前線上版 Hero（藍/黃）與內文（綠）兩套色彩語言**斷裂**的問題（3/20 會議三方共同回饋），並維持品牌辨識（3/11 會議定調）。

## 2. 明暗用色規則（解決螢光綠辨識度）

> 3/20 回饋：螢光綠在淺底不夠明顯。規則：**發光色只在深底發光，淺底改用沉穩色。**

| 元素 | 深色區（迷霧） | 淺色區（藍圖） |
|---|---|---|
| 游標 / 螢火點 | `dawn-gold`、`spark-lime`（發光） | `brand-green`、`deep-pine`（沉穩可讀） |
| 路徑線 | `dawn-gold` 半透 | `brand-green` / `blueprint-teal` |
| 重點文字 | `dawn-gold`、`#FFFDF8` | `brand-green`、主文字色 |
| 徽章 | 金字 + 半透深底 | **填色徽章 + 深字**（金色不單獨當文字色） |

對比度檢核（WCAG）：
- `brand-green #4A7C59` on `mist-white #FBFDF8` → 約 **4.6:1**，大字／粗體 ✓，正文需加深或加粗
- `dawn-gold #F5EF68` on `fog-ink #0C1A18` → **>12:1** ✓（深底發光）
- `dawn-gold` on `mist-white` → 約 1.1:1 ✗（故禁止金色當淺底文字）
- `#1C2B24` on `mist-white` → **>13:1** ✓（正文）

## 3. 「迷霧 → 藍圖」漸層定義

Hero / 深色沉浸段（縱向，深→亮）：
```css
background: linear-gradient(168deg,
  #0C1A18 0%,    /* fog-ink */
  #13332C 34%,   /* deep-pine */
  #4A7C59 72%,   /* brand-green */
  #6FA07D 100%   /* 鄉育綠提亮，銜接淺色內文 */
);
```
光譜總覽（橫向，示意用）：
```css
linear-gradient(90deg,
  #0C1A18 0%, #13332C 24%, #4A7C59 52%, #CFE5D4 78%, #FBFDF8 100%);
```
指引光：晨光金 `#F5EF68` 光點 + 螢火萊姆 `#B8E94A`，沿路徑散佈，深底加 `box-shadow` 光暈。
